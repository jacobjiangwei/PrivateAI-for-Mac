# PrivateAI 隐私政策

生效日期：2026-09-11

PrivateAI 目前是开发版本，并非受支持的正式产品。本政策只描述当前仓库中已经提交的代码；规划中的行为应记录在产品和架构文档中，而不应作为当前数据流陈述。

## 核心 AI 处理

PrivateAI 会把系统提示词、对话上下文、当前请求、已选择的 Tool schema 和 Tool 结果发送给用户本机运行的 Ollama 服务。当前代码未配置云端模型提供方。Ollama 是独立的本机进程，有自己的配置和数据处理方式。

每次用户提问开始时，App 会同步采样一份精简的设备上下文：带 UTC 偏移的日期时间、时区标识符、locale、最多三个首选语言、macOS 版本和处理器架构。同一任务的后续模型和工具回合沿用这份快照，不重新采样或重复追加；下一次提问再刷新。不包含设备名、用户名、序列号或位置，也不把 locale 当成地理位置。

## 保存在 Mac 上的数据

PrivateAI 使用本机 SwiftData 数据库保存对话和消息，包括原始模型请求体、模型思考、中间和最终回复、工具参数及完整工具结果文本。原始请求包含实际发送的系统提示词、工具定义、模型选项、设备上下文和历史消息，可能包含提取的文档正文、路径、搜索词、中间摘要及图片编码。这些诊断消息不会回灌到后续对话历史；删除会话也会删除该会话中的诊断消息。

用户选择的文档还会被复制到 `~/.privateAI/artifacts` 下基于内容哈希管理的存储中。进行整篇文档分析时，逐页、分块和各层归约摘要会作为私有 checkpoint 文件保存在 `~/.privateAI/jobs/document-summaries`，用于中断恢复和相同任务复用。原始会话记录是本地持久化副本，不是临时预览；通过安全终端输入通道传递的密码等交互秘密不得进入模型消息或这些记录。

PrivateAI 会把有界的运行元数据写入 `~/.privateAI/logs` 下的私有文件。当前日志不记录提示词正文、模型回答正文、本地文档路径、本地文档搜索词或本地文档 Tool 输出。应用会进行一次隐私迁移，删除可能包含这些内容的旧开发版本日志。

## 网络功能

PrivateAI 包含公网 Web Tool 和 Apple 服务 Tool。当模型调用网络 Tool 时，请求所需的查询、URL、坐标或其他 Tool 输入可能会发送到对应的公网端点或 Apple 服务。当前代码未实现广告或产品分析。

包含文档附件的对话会进入文档隐私模式。在此模式下，模型只能使用本地文档分析 Tool 和有界本地资源 Tool，不能使用公网 Web Tool 或 Apple 服务 Tool，因此文档内容不能通过这些能力被静默转发。

## 文件访问

用户可以通过系统文件面板选择文档，也可以把 Finder 中受支持的文件 URL 拖到输入区。PrivateAI 只在导入期间访问用户选择的源文件，后续读取使用受管副本。模型可用的文档 Tool 仅能访问受管附件根目录。可搜索 PDF 通过 PDFKit 读取；没有文本层的扫描 PDF 当前不会进行 OCR。

当用户在当前请求中明确写出一个实际存在且受支持文档的绝对路径时，PrivateAI 会仅在本次请求中授权本地文档 Tool 访问该文件。此授权不包括同目录中的其他文件或该文件所在目录。包含本地文档的请求只会提供本地文档 Tool，不会同时提供公开 Web 或 Apple 服务 Tool。

## 安全与保留

当前开发 target 未启用 App Sandbox。受管附件和日志目录权限设为仅所有者可访问（`0700`），受管文件权限设为 `0600`。删除对话会删除对应附件引用，无引用的受管 blob 会由 reconciliation 回收。仅删除 App 不一定会删除 `~/.privateAI` 中的数据；开发者可以删除该目录以移除受管附件和日志。

## 变更与联系

如有重大变更，本政策会更新生效日期。隐私问题请使用仓库的公开支持渠道；安全问题请使用 GitHub 的私密漏洞报告渠道。
