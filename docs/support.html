Help and requirements

PrivateAI for Mac support

PrivateAI is an actively developed native macOS assistant. Signed and notarized builds are distributed through GitHub Releases.

Requirements

The App requires macOS, a running Ollama installation, and a compatible local chat model. Browser computer use additionally requires a model that reports vision and Tool-calling capabilities.

Download and install

Download PrivateAI.dmg and, optionally, PrivateAI.dmg.sha256 from the latest release. Builds are Developer ID signed, notarized, stapled, and Gatekeeper-validated in CI.

The checksum is an optional integrity check:

shasum -a 256 -c PrivateAI.dmg.sha256

Document analysis

Attach a supported document with the paperclip button or Finder drag and drop, or explicitly include its local path in the request. Searchable PDFs and text-based formats support bounded reads and resumable hierarchical summaries. Scanned PDFs without extractable text are not currently supported.

Reporting a problem

Open a GitHub issue with the App version, macOS version, selected model, exact error, and reproducible steps. Do not post sensitive documents, chat transcripts, browser screenshots, API keys, credentials, or private data.

Report security vulnerabilities privately through the repository's security policy.
